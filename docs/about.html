Method

A reading aid, tied to the source.

PolicyPulse is a static site. A daily GitHub Actions job downloads public pages from PIB, RBI, SEBI, CBIC, DGFT, and the Gazette of India, stores each notice as JSON, and rebuilds these pages.

The brief for each notice has three parts: what the official text says, which sector keywords matched, and a next step that tells you to open the source. Sentences about restriction, amendment, timelines, banking instruments, duties, or licences appear only when those words are in the official text.

An optional language model can add a note when the repository secret POLICYPULSE_LLM_API_KEY is set. The site builds and reads correctly with that secret unset. A model note is dropped if it contains a number that was not in the source text.

This is not a government website and not legal, tax, or investment advice.

Built by Nidhi Karuturi. Briefs quote official headlines and never replace the source.
